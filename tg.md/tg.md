# Project

This directory defines the high-level concepts, business logic and architecture of the project in markdown, managed with the `tg` CLI (compatible with lat.md). Run `tg check` to validate it.

- [[code-ontology]] — shared vocabulary of intent types and typed edges between intent and code
- [[decisions]] — architecture decisions for statecharts, actors, storage, agents and verification
- [[constraints]] — external rules from SCXML, RDF, SPARQL, relays, tiramemsu and Aeneas
- [[glossary]] — actor lifecycle classes, mailbox, decider and shard
- [[roadmap]] — milestones M0 to M6 and their order
- [[capabilities]] — every capability, its milestone and its OpenSpec spec
- [[components]] — crates, what they provide and use, and the decisions they realize
- [[views]] — architecture views with Mermaid diagrams, linked to components, capabilities and decisions
