Examples

Six small programs, one idea each. They live in examples/ in the repository, and cargo test -p vertep-examples runs every one and compares what it prints with the output shown on these pages.

An SCXML chart driven through the pure core: a parallel state, delayed sends, a host that owns the clock.

Setup

The Rust examples need only the workspace toolchain. For the vt commands, install the CLI from the checkout, or alias it to cargo:

cargo install --path crates/vertep-cli        # puts `vt` on your PATH
# or
alias vt='cargo run -q -p vertep-cli --bin vt --'

The browser example needs the JavaScript packages built once; its page shows how.

How they stay honest

  • examples/tests/run_examples.rs runs each binary and compares its output with the expected-output.txt next to it. It also runs the Node.js example when Node and its node_modules are present.
  • examples/tests/vt_commands.rs runs the vt commands and compares them with the recorded files under vt/.
  • After an intended change, VERTEP_BLESS=1 cargo test -p vertep-examples re-records the outputs, and python3 site/tools/sync-examples.py rewrites these pages.
