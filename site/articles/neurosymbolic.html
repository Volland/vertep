Article the eighth

The model proposes, the structure disposes

Neurosymbolic agents without the slogan

“Neurosymbolic” is usually said as a hope: the fluency of a network and the reliability of logic, somehow together. This article says what it can mean in a system that has to answer for what it did, and where each half earns its place.

The division of labour

Neural networks are good at what is hard to write down: reading a messy document, weighing a case that does not fit a template, saying something a person can follow. They are bad at being the same function twice, at refusing reliably, and at telling you afterwards what they relied on. Symbolic structure is the other way round. A chart, a rule, a type or a shape is easy to inspect and exactly repeatable, and it cannot read a scanned payslip.

The useful question is not how to blend them but where each one is allowed to act. In Vertep the answer has four layers, and each layer is something you can point at in a journal.

Four layers

  1. The chart says what is possible. A statechart has states and transitions. At a decide state it works out which transitions are enabled right now and offers only those. A model cannot approve what policy forbids, because the move is never on the table. This layer is symbolic and exact.
  2. A decider chooses among the offered moves. It may be a model, a person, a guard in a small expression language, an actor, or a rule program. All of them obey one contract: they receive the offer and return a value; the shell validates it, and an answer outside the offer is refused. The decider is where the neural part lives, or the symbolic part, by choice.
  3. Rules decide, constrain or derive. A rule program can be the decider; it can be an invariant enforced when the journal is written, refusing an append that would break it; or it can derive facts with the statements they follow from. This is the symbolic layer that reasons, and it reads the same facts the journal holds.
  4. The journal records every input. The model's answer is journaled as an input before it is used, so a replay consumes the recorded answer and calls no model. The model is not deterministic; the run is.

Read that as a stack of guarantees, not as a pipeline. The journal makes the run repeatable whatever the decider was. The chart bounds what any decider can do. The rules make the reasoning itself inspectable where reasoning is the point.

What a model is for, here

A model decider is handed the offer with a schema for each candidate, so its structured output has to be one of the offered events with a payload of the right shape. Its rationale and confidence come back as annotations and are stored as a labelled claim. In the loan example the underwriter model may approve, decline or refer; when it tries to approve a case that policy forbids, the chart has already removed approve from the offer, the answer is refused, and the case goes to a person. The refusal is in the record, with the disposition refused-not-offered and the list of what was offered.

That is the first neurosymbolic pattern, and it is the plain one: the model chooses inside a symbolic envelope. Nothing about the model is made more reliable; its failures are made harmless and visible.

What a rule is for

A rule decider turns the same envelope into the decision. Where a policy is a matter of facts and thresholds, there is no reason to ask a model, and a rule gives a better record: a derivation, not a claim (see the previous article). The second pattern is rules as the decider for the routine, a model for the exceptions, wired with a fallback or with a chart that routes by state. The chart decides which decider is asked; the journal says which was.

The third pattern is subtler. A rule is an invariant on the record itself: no approval without a recorded officer review, no entry for a blocked actor. It is enforced at commit, so it binds the model-driven path and the rule-driven path alike, and a violating append is refused, dead-lettered with the name of the constraint, and leaves the journal unchanged. Here the symbolic layer is not a decider at all. It is a guard on the whole system, written once.

Where the model may touch the rules

The interesting direction is the reverse one: a model that helps write the rules. An agent that notices a pattern in refused cases can propose a rule, and the neurosymbolic loop closes: the model proposes, a gate and a trial run on recorded cases test it, a person promotes it, and the promoted program runs as symbolic code the model cannot alter. The next article is about that gate, and about the one rule it is built around: an actor never changes the rules that govern it.

What this is not

It is not a claim that the combination is more accurate. A rule is exactly as good as the policy it encodes, and a model is exactly as good as it is. It is not a proof that the system is fair or lawful either; the verification pages in the docs are explicit about what each check does and does not cover. What it buys is narrower and, for regulated work, usually what is asked for: every decision has a named decider, a recorded offer, a disposition, and either a derivation or a labelled claim; the structure that bounds the model is code you can read; and the same journal replays whatever mix of deciders produced it.

Whether the pieces are the right ones is a question for the book too: The Goat Does Not Choose the Play spends its third part on neurosymbolic agents, deciders, and rules and derivations, on a worked lending case. The docs pages for agents and deciders and rules are the reference.
